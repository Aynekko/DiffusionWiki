A few example maps to help you learn level creation for Diffusion.

Chapter 2 Desert

The middle section of Chapter 2. The biggest map Diffusion has to offer, although not the most detailed.
This map has land vehicles, such as the Buggy, Hummer, Cybertruck, Jeep, and water vehicle such as the Jetski.
The map has dynamic weather change mechanic - sandstorm.

Download MAP | Download JMF (last updated: 29 Apr 2026)

dm_test

A multiplayer map which has practically everything that Diffusion has to offer.
The map features dynamic weather mechanic (heavy rain), an APC vehicle and a semi-cut Shield mechanic, which was supposed to be featured in the campaign but was cut very late in development. The shield code is still there, so it has been repurposed for multiplayer.
