Mapping setup

To make maps for Diffusion, I used J.A.C.K. editor.
Other editors like Trenchbroom or Valve Hammer Editor were not tested.
You can get free version of J.A.C.K. here or Steam version (paid) here.
It is recommended to use Steam version as it updates more often, but the free one should work just fine.

Map compilers

For Diffusion I use edited compilers from PrimeXT
A few minor changes were done to them - for example handling of the Diffusion-specific cubemaps, so it is important that you use these compilers and not from original PrimeXT (my fork of PrimeXT here)

The file below includes 4 exe files - csg, bsp, vis and rad. You must set them up in the editor.
Download map compilers

Compiling the map

Press F9 in J.A.C.K. and "Run Map" window will open. Switch to Expert mode.

In VIS parameters, specify -threads parameter to specify the amount of CPU threads that will be used for compilation.
It is recommended to set the number of threads less than what you have in total, so you'll have one or two free threads for basic tasks while you wait for the map to compile.

In RAD parameters, you can specify the ones below. These were used to compile all Diffusion maps. You can tune them to your liking if you know what you're doing. Otherwise I recommend to just use these. Also don't forget to add -threads here as well. 

-smooth 45 -bounce 32 -blur 2  -accurate_trans -envsky -studiobounce 4 -sky 0.425 -texchop 64
